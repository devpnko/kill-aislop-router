# Changelog

## Unreleased

- Added an optional, resumable reference-intelligence stage that binds an
  approved service-planning frame, rights evidence, bounded UI Bowl queries,
  popularity provenance, distinct researcher/critic children, and a real
  Owner selection. Deterministic ranking applies popularity only inside equal
  product-fit bands, and the compiled pixel-free grammar pack remains
  `discovery-evidence-only` without visual or creator authority. Atomic state
  leases, exact child checkpoints, idempotent crash recovery, tamper rejection,
  pinned single-descriptor authority inputs, critic-verified component/pattern
  coverage, and real child-process regressions preserve fail-closed execution. The
  existing exact-three 3×3 design route remains unchanged.

- Closed the standalone audit CLI's `--run` read race by binding path checks,
  parsing, and provenance to one descriptor before dispatch, ingest, triage,
  status, or finalization. Sealed adapter discovery now distinguishes the CJS
  loader's `require()` from locally shadowed functions, variables, parameters,
  catch bindings, and arrow parameters; ESM-local `require` helpers are never
  misclassified as module loads.

- Made the packaged-router exception consistent across start, resume, stale
  lease recovery, and verified legacy migration. Declarative router policy may
  be root-owned or hard-linked by a global/content-addressed installer, but its
  bytes and physical identity remain journey-bound; profiles, approvals,
  manual evidence, and custom executables retain caller-owned single-link
  requirements. Official Codex manifest validation now probes the already
  verified source runtime and reuses its digest-bound readiness cache without
  cloning the complete runtime once per provider. The actual reviewer child
  still executes only from a fresh private runtime seal.

- Preserved the documented standalone kill-ai-slop scanner-to-audit workflow
  without weakening parent identity: only the exact unbound compatibility
  receipt may be parent-bound at ingest after real artifact path and digest
  verification, while any partial packet binding fails closed. Audit
  initialization now derives plan/profile provenance from the same pinned
  descriptors used for parsing and revalidates external authority before
  returning. Secure path checks also canonicalize only verified root-owned
  macOS `/tmp` and `/var` aliases, retaining symlink rejection everywhere else.
  Child evidence grants now use that same canonical path guard before choosing
  an implicit output root, so a pre-existing symlink ancestor cannot become its
  own trust boundary. Persisted grant/output device and inode markers are
  lossless decimal strings; resume still accepts legacy safe-integer markers.

- Replaced raw-regex module discovery with comment/string/template/regex-aware
  lexical extraction so prose cannot invent a sealed dependency. Literal
  imports inside nested template expressions and arbitrarily wide named
  import/export clauses remain part of the sealed graph. Mixed ESM/CJS
  adapters remain supported through static ESM imports or CJS literal
  `require()`; custom ESM `createRequire()` is now explicitly documented as a
  fail-closed security migration because it would bypass descriptor-fed bytes.
  The long child-process E2E inventory is sharded across isolated test files and
  has its own explicit command, while `npm test` remains a bounded contract and
  security suite. This keeps constrained reviewers from terminating one
  monolithic worker near 120 seconds without dropping E2E from CI or release
  verification.

- Aligned official Playwright manifest validation with the exact child handoff
  contract: unsafe baseline filenames, nested entries, non-regular files, and
  baseline sets over 64 MiB now fail during configuration or manifest load
  instead of at browser spawn. Restored the exported execution API's compatible
  recursive creation of fresh nested output directories while retaining an
  atomic physical grant at the nearest existing ancestor; explicit grant roots
  remain mandatory boundaries when supplied.

- Kept the profile-bound Playwright verification contract portable by binding
  runtime content but leaving inode/owner/timestamp identity in host-local
  preflight and child authority. Trusted bundled router/adapter assets now work
  under root-owned and content-addressed hard-link installs without relaxing the
  caller-owned single-link rule for custom executable or owner/evidence inputs.
  Standalone kill-ai-slop scans seal multi-file scanner graphs automatically,
  and the exported Codex runtime-seal creator/verifier now share one canonical
  object contract. Independent-review regressions cover all four boundaries.

- Hardened release identity and child-start boundaries after independent
  adversarial review. Codex plugin readiness now requires a deterministic marker bound
  to the trusted packaged payload, copied Playwright/axe runtime, canonical
  namespaced skill, and package version; pre-integrity markers require an
  explicit backed-up refresh, while empty/self-authored markers fail closed.
  The marker carries no self-asserted installer, source-path, or timestamp
  provenance. Legacy migration verifies the exact packaged explicit-only shim
  bytes and a shaped digest-bound backup, and binds the shim to the actually
  installed canonical marker, payload, runtime, and skill digests. Reviewer spawn now re-pins the current project
  profile, visual authorities/evidence, file artifacts, and owner approval by
  content digest and physical identity. Adapter entrypoints and their explicit
  local dependency graphs are sealed from manifest-time bytes (maximum 256
  modules, 512 KiB each, 8 MiB total), checked again at the final child
  boundary, and executed through a descriptor-fed loader, so neither
  entrypoint nor imported-helper replacement can execute replacement code.
  Multi-module declarations require a reviewed `entrypoint_graph_digest`;
  official configuration creates it automatically. Official Playwright
  normalizes manifest-relative scenario/runtime/baseline paths, restricts the
  runtime to the bundled executable trust boundary, and sends parent-pinned
  scenario and baseline bytes in a digest-bound child authority. A final source
  confirmation blocks observed path and same-content inode/directory
  replacement before spawn; the child never reopens mutable scenario or
  baseline paths. Regression coverage includes sequential multi-authority
  swaps and plan, profile, visual, artifact, entrypoint, scenario, baseline,
  and approval replacement.

- Closed the nested-runtime TOCTOU boundary. Official Codex configuration now
  binds physical identity for both the executable and complete runtime root;
  probes and reviews execute only a verified private clone. Official
  Playwright binds the physical identity of its two pinned npm package trees,
  copies them into a private runtime, and requires the child to verify and load
  that seal before network or browser work. Same-byte replacement before or
  during either copy fails closed, with regression coverage.

- Added opt-in, digest-bound parent-baseline/slice lineage through planning,
  automation state, audit packets, child requests, phase/final receipts, and
  owner scope. Newer slice versions cannot promote themselves to parent;
  parent/candidate tamper and resume conflicts fail before another child runs.
  Raw planning declarations and digest-required runtime copies use separate
  schemas; canonical paths, symlink components, recursive filesystem identity,
  route-plan anchoring, hard-link rejection, and a final pre-spawn recheck close
  alias and TOCTOU downgrade paths. No-lineage runs omit lineage-only fields;
  independent router/resume/lease security additions remain documented.
- Added a caller-visible `<state>.authorities/<run-id>.json` receipt, durably
  written before the first modern state. Its version-5
  `resume_authority_digest` binds the original router, profile, request,
  artifact digests, parent journey, full path contract, and initial canonical
  plan-authority digest before a modern resume may trust state-selected paths.
  That digest includes the selected planning receipt and optional lineage;
  persisted plan, audit, and packet facts are additionally bound by their phase
  and audit receipts. Fault-injected crashes after authority issue,
  initial state, every plan/planning/audit/dispatch sidecar and receipt boundary now
  recover into one idempotent initialization without spawning a duplicate
  reviewer or incrementing completed bootstrap attempts. Existing canonical
  sidecars or fixed receipts that are not bound by current state are always
  rejected during normal resume as ledger rollback. Only the active authorized
  stale-lease recovery may seal them; recovery receipt version 3 binds the root
  stale lease, prior state digest, deterministic reconciled anchor IDs and steps,
  and the external initialization graph digest without a circular final-state
  claim. Orphan anchors and recovery receipts are adopted only when their exact
  bytes match reconstructed authority, so a crash inside recovery cannot rewrite
  them or increment bootstrap attempts. After dispatch and before any child
  starts, a second caller-retained `<run-id>.initialization.json` authority
  binds the immutable initialization graph. Deleting both state bindings and
  all mutable sidecars therefore cannot replay reviewers; an orphan commitment
  may be adopted only by the active authorized stale-lease recovery.
  The complete caller-visible authority directory is protected across every
  child process boundary; deletion, replacement, or addition leaves the child
  intent unresolved and the exclusive lease held for recovery. Route plans,
  routed router/profile inputs, visual authorities, planning/owner decisions,
  phase and migration receipts, start/initialization authorities, recovery
  inputs, final receipts, and Playwright scenarios now derive parsing and
  SHA-256 from one pinned descriptor and reject path replacement during read,
  including the final route-plan check immediately before a reviewer child.
  The authority also binds the complete
  canonical parent-owned path contract for plan, audit, packets, results,
  evidence, phase and migration receipts, and the final receipt. Re-signed
  redirects of any persisted parent sidecar or phase receipt outside the state
  `.d/` tree fail before child spawn or ledger write; approval, triage, and
  manual-result sources remain read-only provenance. Coordinated local
  re-signing, forged
  legacy invocation, creator-actor substitution, source-less audit APIs, and
  complete audit enforcement-graph downgrades now fail closed before child
  spawn. Legacy migration now requires a byte-identical external pre-mutation
  backup plus its caller-retained file digest, accepts only an allowlisted
  historical router digest and captured state/plan/audit fingerprints, rejects
  stripped modern states even when they reuse the allowlisted router, stages
  migration sidecars copy-on-write, and issues a new resume authority binding
  the backup and migration provenance.
- Required integrated approval, scanner-triage, and manual-result inputs to be
