# Scoped source-to-target craft review

This optional **candidate capability** adds a separate source-aware critic to the
reference-per-candidate route. It does not turn KSR into a creator or grant anyone
new source rights. Check `capabilities --json` for `scoped-source-craft-review` in
the CLI actually executing the journey. A source checkout or package is not an
installed delivery.

The previous `promotional-citation-firewall` and `source-composition-independence`
purposes remain unchanged. Neither authorizes a source-craft judgment. Existing
target-only specimen review still compares renders with source-neutral recipes,
not source pixels. Historical states are not upgraded or re-signed.

## Explicit opt-in before creation

Use a new `reference_candidate` brief with its existing verified selected pack,
component relationships, visual goals and constraint audit. Add:

```json
{
  "source_craft_review": {
    "provider_id": "independent-source-craft-critic",
    "authority": {
      "path": "authority/source-craft.json",
      "digest": "sha256:REPLACE_WITH_ACTUAL_FILE_DIGEST"
    }
  }
}
```

This is a binding fragment, not a fabricated usable grant. The external authority
must satisfy [the authority schema](../schemas/source-craft-authority.schema.json).
It names the project, screen, comparison, exact candidate, primary reference,
verified pack and producer; it binds the reviewer provider **and actor**, allowed
capture digests and separately pinned rights evidence. The issuer must be outside
the participating creators/reviewers. Keep authority and rights evidence outside
the creator baseline and every child-writable run directory.

The external grant also pins `task_frame_digest` (including the exact baseline)
and `cohort_digest` (the canonical digest of normalized predeclared state paths).
Changing that frame or candidate membership requires new external scope, not a
rewritten local packet. All members of a comparison must use the same opt-in mode.

Rights assertions are attributed protocol evidence, not automated legal license
verification. A page being public, a paid membership, a prior Owner direction or
this feature's existence does not establish permission. Source access, target
creation permission and Owner visual approval are separate. No creator/browser
source access, redistribution, external network, literal copying, authorship
certification or Owner approval is granted by this authority.

Declare relevant comparison slots rather than a decorative universal matrix.
Each slot binds a target relationship, permitted source capture and actual target
viewport/state/locale. Cover recipe-backed relationships; explicitly identify
target inventions. Desktop evidence cannot prove a source's mobile behavior.
Record what each frame can support: gallery images and small thumbnails may show
broad composition while failing to support exact type, spacing or control detail.
Encoded PNG dimensions do not reveal CSS viewport, zoom or device-pixel ratio.

## Execution and privacy

Use the existing `design run --brief ... --baseline ... --out ... --host-config ...`
and `design run --resume ... --host-config ...` commands. No alternative CLI,
custom browser proof or profile command is introduced.

The sequence is creator → official browser → target-only specimen critic →
separately authorized source-craft critic → specimen feedback. Before any source
handoff, **all predeclared cohort members** must already have immutable accepted
creator, official browser and target-critic results. Missing peers remain pending;
they are not silently removed from the cohort. This permits the single-candidate
case while preventing source exposure to an unfinished sibling's participants.

The new reviewer requires capability `source-target-component-craft-review`,
strength 4 and permissions `artifact:read`, `evidence:write`,
`reference-evidence:read`; `network:external` is forbidden. A missing approved
adapter remains `manual_pending`. A genuinely manual result uses the emitted
packet and existing `--result` ingest and remains manual, not an executed child.
An automated host must bind `settings.actor_id` to the authority's fixed reviewer
actor before it receives captures; a mismatching identity is not merely a later
result-validation warning. The private packet identifies the intended manual
reviewer separately from the provider.
Creator, browser and target-only critic must not receive source images, source
review output or its private report. Raw source-aware observations must not be
forwarded as a repair prompt; that would create a new disclosure path, not an
allowed continuation of this contract.

For this new opt-in only, CLI run/resume/status output is a typed
`design_public_state_version: 1` summary, including status, counts, participant
packet/result digests and the private ledger location. It intentionally omits
full authority documents, raw results, capture/report paths and child diagnostic
prose. Existing no-opt-in CLI output is unchanged. On-disk state and the library's
`readDesignState` remain private, full-evidence interfaces; do not publish them or
pass them to a creator. Pending cohort members that never complete require an
explicit abandonment/rejection or separately scoped successor, not a waived grant.

Only permitted primary-reference capture bytes reach this reviewer. The packet
binds accepted target renders, source evidence and the immutable cohort participant
history. Aliased actors/executables and uncertain crash-exposure history block
handoff. These are protocol identity and digest checks, not an OS sandbox or proof
that a human or process has forgotten sources seen elsewhere.

## What a result establishes

The [review schema](../schemas/source-craft-review.schema.json) binds the authority,
candidate result, browser result and each actual screenshot including locale.
Each slot records retained/adapted/lost/unassessed relationships, adequacy and
limitations. Adaptations need a rationale: accessibility, task content and locale
may justify differences. No numerical beauty score or pixel-similarity threshold
substitutes for this judgment.

Insufficient source evidence or a lost/unassessed relationship remains a hard
blocker. Technical tests, a local spacing repair and within-pool ranking cannot
erase it. Public comparison output includes only bounded verdict metadata and
digests, not private reviewer prose or source pixels. Accepted scoped review is
not universal parity, human authorship, G7 or final design-system approval.

The real Owner still chooses an eligible rendered candidate or rejects all.
Selection freezes the exact HTML handoff; further expansion and systemization
retain their separate product, browser, reviewer and Owner gates. If a grant,
pack, target or reference must change, prepare an explicitly scoped successor;
never rewrite accepted evidence.
