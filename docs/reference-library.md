# Search the component research library

Use `killsloprouter reference library` (or an already configured `ksr` alias)
to find task-related source analysis before new collection. It is an offline,
read-only lookup, not a project reference run, fit ranking, Owner selection,
creator dispatch or component installer. No project profile is read and no
state, receipt, lease, browser, network or child process is started.

```bash
node bin/killsloprouter.mjs reference library --query 브리핑
node bin/killsloprouter.mjs reference library --query '검색/탭' --json
node bin/killsloprouter.mjs reference library --component watchlist-detail --details
node bin/killsloprouter.mjs reference library --source toss-securities --json
```

From an installed package, use its actual CLI path, not the checkout command.
Check `capabilities --json` for `reference-research-library`; a Git push does not
update the installed plugin. This change does not create or replace a host alias.

## What is searched

The initial library pins the [30-frame component study](research/ui-bowl-korea-component-study-2026-09-22.md),
its JSON, original source index and exact independent **manual study** review.
It contains 14 component analyses from 10 product/surface groups in five
ecosystems, not 30 complete products or 14 approved implementation components.
Any changed bound bytes, unresolved review, or widened authority fails closed.
The older [candidate catalog](reference-catalog.md) and [part study](reference-application-map.md)
remain separate research records; their counts are not added as new unique frames.

| Need | Component ID | Bound source scope, not a chosen theme |
| --- | --- | --- |
| Summary with original | `summary-with-source` | Call transcript and summary |
| Briefing card and reading | `briefing-card` | Dated financial briefing |
| Choice and input error | `choice-dialog` | Payment-method management |
| Image-led discovery | `media-discovery` | Travel discovery and detail |
| Hierarchical search | `hierarchical-search` | Destination selection |
| Help and disclosure | `help-disclosure` | Map help centre, **not map interaction** |
| Editor and preview | `composer-preview` | Merchant notification composer |
| Local writing help | `contextual-writing-assistant` | Proposal/rationale/apply near input |
| Numeric list and issue sheet | `watchlist-detail` | Watchlist and grouped issues |
| Time-ordered news | `news-timeline` | News rows in a sheet |
| Paired input/output | `dual-pane-handwriting-input` | Translation and handwriting helper |
| Multi-step registration | `payment-registration` | Narrow web payment panel, **not mobile proof** |
| Mixed search and tabs | `mixed-search-palette` | Entity/news/related results; one frame |
| Dense comparison modules | `data-workbench` | Market home and trading workbench |

`--component` and `--source` use exact IDs. `--query` accepts Korean or English,
normalizes Unicode and case, and AND-matches terms separated by spaces, `/`,
`,` or `·` across the task, label, source name and curated search keywords.
It does not search incidental words inside every recipe or claim semantic AI
matching. Keywords are researcher-authored facets, not independently verified
project fit. Unknown valid IDs and queries return zero matches without a style
fallback. Malformed/repeated flags fail with exit 2; corrupt bound evidence
fails with exit 5. A successful lookup, including zero matches, exits 0.

No filters lists all component entries. The report exposes available IDs, exact
frame links, conditions, harmful contexts, limits and hashes. `--details --json`
adds the full observations, causal hypotheses, anonymous draft recipe and
proposed checks; text `--details` shows visual observations and target check
proposals. Source frames shared by entries count only once. Display order is study
order, **not** popularity or project fit ranking.

The full report includes source identities and is for researchers, critics and
the Owner. It is **not** a creator-safe packet even though each embedded draft
recipe is source-neutral. Source pixels, capture paths and account values are
not distributed. Static appearance does not prove source clicks, hover/focus,
mobile reflow, accessibility, current popularity or human authorship.

## From lookup to a real specimen

1. Match the actual project job, locale, states and risk; use its external
   planning and scoped research/rights authority. A library query cannot supply
   those inputs or upgrade a help screen into an operational map reference.
2. Revalidate source access and capture coverage in a project-local reference
   brief/export. Use the existing independent discovery/grammar/critic stages.
   The library's manual study review is not a `reference-review` result for a new
   project. Prior capture ownership does not transfer rights or Owner choice.
3. Present `reference choices --run ... --json` when that run is eligible. The
   real Owner selects an anchor, supports and grammar; do not submit the first
   search result as their choice. Compile and bind the exact ready pack.
4. Use [component recipes](component-recipes.md) in the unchanged design route.
   Actual target values, selectors, states, three distinct widths, independent
   browser/critic evidence and exact Owner stops remain required. The three
   specimen families are not a replacement for the exact-three 3×3 matrix.
5. Only approved, independently audited artifacts can proceed to the existing
   G6T/G7 systemization route. No library entry is an approved shared component.

The [three-family verification proposal](research/component-specimen-verification-proposal.md)
separates prepared research from missing execution gates. Missing authority or
selection means no creator is started; it does not block the read-only lookup.

## Validate the delivery

```bash
npm run test:catalog
npm test
npm run pack:check
```

Package checks exercise isolated npm/plugin consumers and exact library results.
They do not install the user's Mac plugin or certify a real project UI. Keep
historical study/receipt bytes unchanged; add a reviewed successor and update
the lookup index deliberately when evidence changes.
