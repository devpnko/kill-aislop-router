# 국내 컴포넌트 연구 2차: 접근 확인

2026-09-23 KST · KillSlopRouter · 현재 상태 **Owner 로그인 대기**

새 연구 탭에서 UI Bowl 홈페이지와 멤버십 링크를 일반 브라우저로 열었다.
두 화면에 로그인 버튼이 표시됐다. 현재 계정의 유료 등급이나 전체 이미지
열람 권한은 확인하지 못했다. 공개 멤버십 안내는 Starter의 탐색 범위를
최신 3개 앱·웹사이트로, 개인/그룹 Pro의 범위를 전체 앱·웹사이트로 설명한다.
이 안내는 계정의 실제 구독 증거가 아니다.
[확인한 페이지](https://uibowl.io/membership)

기존 탭의 과거 프로필 표시, 이미지 바이트의 존재, 캡처 해시 일치만으로
당시의 유료 접근 권한이나 재사용 허가가 입증되지는 않는다. 이번 확인도
기존 30장의 수집 권한을 소급 승인하지 않는다. 기존 연구·검토 기록은
그대로 보존한다.

## 지금 진행하는 범위

- 보존된 정적 연구의 서술을 서비스 간 컴포넌트 선택 기준으로 비교한다.
- 관찰, 연구자 해석, 타깃 제안을 구별한다. 원본 픽셀을 다시 관찰하거나
  새 서비스 화면을 확보했다고 주장하지 않는다.
- 상품/가게 목록·상세, 실제 지도·위치 선택, 긴 본문 읽기, 같은 제품의
  여러 폭과 상호작용 자료 공백을 유지한다.
- 가입·결제·계정 전환, 쿠키/토큰 조회, 내부 API·이미지 주소 접근,
  MCP 활성화, 접근 제한 우회는 하지 않았다.

로그인은 Owner가 정상 브라우저에서 직접 진행하도록 요청했다. 새 구독
결제를 요구하거나 수행하지 않는다. 로그인 후에도 실제 계정의 표시된
권한과 해당 화면의 정상 열람 여부를 확인해야 한다. 이전에 저장한 이미지가
있다는 이유로 제한된 신규 수집을 계속하지 않는다.

## 아직 실행하지 않은 것

새 제품 프레임 수집 0장, 실제 시안 0개, 원 서비스 동작 실행 0건이다.
기존 42개 반응형 변형과 65개 적용 검사는 여전히 제안이지 실행 증거가 아니다.
정식 프로젝트 reference run, Creator 실행, Owner 선택, 디자인 승인 및
Mac 플러그인 업데이트도 하지 않았다.

실제 검증용 화면 제작은 [기존 제안](component-specimen-verification-proposal.md)의
프로젝트 기획·참조 권한·독립 검토·Owner 선택을 거친다. 새 연구는 준비를
돕지만 그 게이트를 대신하지 않는다. 원본 픽셀은 비공개·gitignored 보관에
남기고 공개 자료에는 자체 분석·출처 링크·경로 없는 해시만 둔다.

[시점별 접근 기록](ui-bowl-second-pass-access-2026-09-23.json)은 홈페이지와
멤버십 캡처를 각각 고정한다. 이를 KSR 공식 Playwright 디자인 실행 증거나
새 이미지 배치로 세지 않는다.
