2026-09-23 · KillSlopRouter · `derivative-of-reviewed-static-study` · `research-only`

핵심은 서비스의 우열이 아니라 **어떤 과업에서 무엇을 보존해야 하는가**다.
검토된 14개 항목 중 같은 결정의 대안을 비교할 수 있는 11개를 중복 없이
5개 문제로 묶었다. 인용 범위는 기존 9개 제품/화면군의 25개 프레임이며,
새로 확보하거나 원본 픽셀을 재검토한 수가 아니다.

정식 reference pipeline 실행 결과 또는 독립 승인서가 아니다.
서비스의 ‘예쁜 부위’를 임의로 섞는 지침도 아니다. 실제 적용에서는 진짜 Owner가
선택한 anchor/support와 공통 타깃 토큰·상태·밀도 문법의 정합성을 따로 검증해야 한다.
