# 국내 친숙 서비스 우선: UI Bowl 1차 30장

상태: **정적 화면 확보·연구자 관찰 완료 / 독립 검토·프로젝트 선택 미완료**.
2026-09-22에 일반 UI Bowl 브라우저 화면에서 확인한 자료다. 현재 서비스
자체를 실행한 감사도, 30개 서비스를 정밀 분석했다는 주장도 아니다.

Owner의 “국내 사람들이 다아는 서비스 위주” 요청에 따라 기존 해외 우선
수집분은 비교 자료로 보존하고, 국내에서 익숙한 서비스·브랜드를 우선하는
별도 배치를 만들었다. 친숙도는 이번 조사 대상 선정 기준이지 전 국민을
대상으로 검증한 조사 결과가 아니다.

불완전하게 디코딩된 네이버 여행 캡처 하나는 재확인한 완전한 이미지로
교체했고, 이전 캡처는 제외 사유와 함께 보존했다. 30장에 두 번 세지 않았다.

## 선정 순서와 인기의 한계

1. 국내 친숙 서비스라는 이번 조사 범위에 먼저 맞춘다.
2. UI Bowl의 한국 필터와 앱/웹 각각의 `MAU 많은순`을 탐색 출발점으로 쓴다.
3. 실제 과업 화면인지, 새로 관찰할 컴포넌트·상태가 있는지 확인한다.
4. 노출된 자료가 홍보용이거나 과업이 다르면 그 사실을 기록하고 보류한다.

한국 필터에도 해외 서비스가 표시되어 필터 자체를 국내 친숙도의 증거로
쓰지 않았다. UI Bowl의 MAU는 **출처에 표시된 숫자**로만 기록했다. 각 수치의
측정 월·지역·집계 방식은 이번 조사로 확인하지 못했다. 앱과 웹의 다른
수치를 합산하거나, 모회사 이용자를 사업자 화면의 이용자로 해석하거나,
“국내 트래픽 상위 10개”라고 표현하지 않는다. 화면의 아카이브 월도 MAU의
측정 월이 아니다. 인기나 친숙도가 과업 적합성·권리·접근성·품질 승인보다
우선하지 않는다.

## 실제 디자인에서 얻은 단서

다음 설명은 보이는 사실에 기반한 **전이 가설**이지, 원 제작자의 의도를
확인한 인터뷰나 그대로 복제할 규칙이 아니다.

- **카드가 아닌 정보의 중요도를 먼저 다르게 한다.** 토스증권 홈에서
  뉴스 사진은 크고 보유 목록의 식별자는 작다. 카카오페이는 같은 목록에서도
  이름·변동 수치·보조 코드를 다른 무게와 정렬로 보여 준다. 모든 항목을
  같은 크기 카드로 만들면 비교와 탐색의 우선순위가 사라질 수 있다.
- **면·선·그림자는 역할에 따라 다르다.** 도움말 목록은 선 중심이고,
  요약은 별도 면, 검색·AI 제안은 위에 뜬 패널이다. 그림자를 전부 없애거나
  모든 구획을 둥근 카드로 만드는 것이 공통 정답은 아니다.
- **색은 브랜드 장식만이 아니라 상태·행동을 구별한다.** 파파고의 활성 입력,
  컬리의 등록 행동, 증권 화면의 변동 방향은 각각 의미가 다르다. 색 자체보다
  역할을 연구하고, 새 제품에서는 자체 팔레트·명도·비색상 단서를 검증한다.
- **정보를 줄이기보다 층을 나눈다.** 원문과 요약, 그룹과 관련 뉴스,
  작성과 미리보기, 초안과 검토 요청이 분리된다. 단정해 보이게 하려고
  출처·시각·제약·상태를 지우면 안 된다.
- **빈 상태와 입력 중 상태에도 시각 설계가 있다.** 필기 보조창,
  가린 카드 입력, 국소 제안 로딩, 오류 확인창을 함께 봤다. 정상 화면만
  보고 같은 모양의 로딩·오류·등록 완료를 만들면 상태를 구별하기 어렵다.

폰트 파일·정확한 CSS·색상 토큰을 추출한 것은 아니다. 인덱스의 크기·명도·
간격·깊이 설명은 정적 화면의 상대적 관계다. 실제 프로젝트에서는 이를
자체 타입 스케일·간격·색 역할·구체적 컴포넌트 값으로 설계해야 한다.

## 부족한 자료를 유명한 이름으로 덮지 않는다

네이버·토스·쿠팡·당근·네이버 지도·배민·무신사·컬리 앱에서 현재 우선 노출된
홍보 이미지는 운영 UI 30장에 넣지 않았다. 일부 일반 패턴 필터가 0건을
반환한 것도 기록했다. 이는 이번 접근에서의 제한이지 서비스 전체에 자료가
없다는 뜻은 아니다. 네이버 웹툰 웹의 노출 그룹은 광고 가이드 센터여서
소비자 감상 화면으로 사용하지 않았다.

확보한 네이버 지도 고객센터는 지도 UI가 아니고, 토스 비즈니스는 일반
토스 앱이 아니다. 컬리 웹의 좁은 결제 패널은 동일 제품의 반응형 모바일
검증을 대신하지 않는다. 정적 캡처의 키보드 안내·토스트·로딩 표시 역시
실제 키보드·복사·비동기 실행 성공의 증거는 아니다.

따라서 다음 우선순위는 화면 수를 더 채우는 일이 아니라 아래 과업의 공백이다.

- 당근·배민·무신사 등 소비자 탐색, 상품/가게 목록·상세·주문.
- 도움말이 아닌 실제 지도·위치 선택·길찾기.
- 긴 본문과 원문/근거 관계를 함께 보여 주는 읽기 화면.
- 같은 제품의 작은/중간/큰 화면 및 주요 상호작용·접근성 상태.

현재 배치는 금융·입력과 네이버 계열 비중이 높다. 모든 제품에 맞는 대표
디자인 모음이 완성된 것은 아니다. 정상 접근에서 필요한 자료가 제공되지
않으면 추가 접근/자료를 기다리며, 홍보 이미지나 다른 과업으로 메우지 않는다.

## KillSlopRouter에서 사용하는 경계

이 인덱스는 연구자·독립 critic·Owner용 탐색 자료다. `reference_pack`,
manual export, 실행 가능한 component recipe가 아니며 creator 입력으로
직접 보내지 않는다. 기존 [part map](../reference-application-map.md)과
[candidate catalog](../reference-catalog.md)의 역사적 자료도 소급 승격하지 않았다.

실제 제품에는 서비스 기획과 과업 적합성에 맞춰 다시 좁힌 뒤, 해당 범위의
권리·캡처·[component recipe](../component-recipes.md), 독립 검토와 실제 Owner의
anchor/support 선택, capture-ready pack을 거친다. 이후에도 후보별 브라우저
검사와 디자인·색·정확한 결과물 승인은 별도다. 이번 연구가 모델 가중치를
학습시키거나 현재 Mac 플러그인을 업데이트한 것은 아니다.

[UI Bowl의 고지](https://uibowl.io/)는 콘텐츠 권리를 원 권리자/제공처에
두고 있다. 공개 요약과 링크는 픽셀·에셋·문구의 재배포 허가가 아니다.
이 문서에는 독자적인 분석과 출처 링크만 있으며 소스 화면을 포함하지 않는다.
